HAO // SYSTEM GUIDE

HOW THE SYSTEM WORKS

This interface explains the operation of the Hydro Automated Operator (HAO), from waste detection and claw collection to container monitoring and notification. Select a controller below to view its function.

STEP 01
S

Detection

The ultrasonic sensor detects the presence and distance of waste in the operating area.

STEP 02
C

Collection

The claw mechanism moves downward toward the detected waste and performs the scoop operation.

STEP 03
F

Filtration

The collected waste proceeds through the HAO waste and oil/sebo processing section.

STEP 04
M

Monitoring

The container level is monitored to determine whether the collected waste is approaching capacity.

STEP 05
N

Notification

When intervention is needed, the notification function informs the owner or responsible person.

CONTROLLER NAVIGATION

SELECT TO VIEW
ESP

ESP32 — MAIN CONTROLLER

›
The ESP32 acts as the main controller of the HAO system. It receives sensor information, processes the programmed conditions, and sends commands to the connected components to coordinate the operation.
US

ULTRASONIC SENSOR

›
The ultrasonic sensor measures the distance between the sensor and an object. In HAO, this information is used for waste detection and container fullness monitoring.
MD

MOTOR DRIVER

›
The motor driver receives control signals from the ESP32 and provides the required motor control for the claw mechanism.
CL

CLAW MECHANISM

›
The claw performs the main collection movement. It moves downward, performs one scoop when the programmed condition is reached, waits for the collection interval, and then moves upward.
LS

LIMIT SWITCH

›
The limit switch identifies the upper position of the claw. When the claw reaches the upper limit switch, the movement stops and the system can proceed with its programmed return sequence.
CN

CONTAINER MONITORING

›
The container level is monitored using the sensor. The system checks the measured distance against the programmed level to determine whether the container is empty, partially filled, near capacity, or full.
NT

NOTIFICATION SYSTEM

›
The notification function provides an alert when the container reaches its programmed capacity or when human intervention is needed.

HAO OPERATION FLOW

PROCESS SEQUENCE
01 — DETECT

Ultrasonic sensor checks for waste or container level.

02 — MOVE DOWN

The claw moves downward toward the collection area.

03 — SCOOP

The claw performs the collection operation once.

04 — MOVE UP

After the programmed delay, the claw moves upward.

05 — LIMIT / RETURN

When the upper limit switch is reached, the upward movement stops and the cycle returns to its programmed state.
